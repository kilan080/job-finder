A job finder app that helps job seekers find relevant job opportunities across different location with ease.

# Job Finder 🚀

## Features

- Search for jobs based on location
- Filter jobs by category
- View job details
- Check job authenticity
- Save jobs for later

## Tech Stack

- HTML
- Tailwind CSS
- TypeScript
- React
- Next.js
- Firebase
- Google Maps API
- Google Geocoding API

## Installation

- First clone the repo
- Install dependencies: cd job-finder && npm install
- Run the app: npm run dev

## Usage

- Open the app in your browser
